ESCUELA UC VILLA ALEMANA — WEB CON PREINSCRIPCIÓN

Contenido:
- index.html: estructura de la página y la ficha imprimible.
- styles.css: apariencia y diseño adaptable a celular/PC e impresión A4.
- script.js: menú móvil, validación, ficha y enlace a WhatsApp.
- assets/: escudos, afiches y logotipo LIVORNO en blanco.
- ficha-inscripcion-uc-villa-alemana.pdf: ficha en blanco para imprimir y completar a mano.

Cómo usar:
1) Abre esta carpeta en Visual Studio Code.
2) Abre index.html con Live Server o directamente en un navegador.
3) En la sección «Inscripciones», completa los datos y pulsa «Generar ficha».
4) Usa «Imprimir / Guardar PDF» y selecciona Guardar como PDF en el diálogo del navegador.
5) «Avisar por WhatsApp» abre una conversación al +56 9 2680 7340 con un mensaje de coordinación que NO incluye datos del menor.

IMPORTANTE — Alcance del sistema
Esta es una web estática. El formulario NO guarda datos en una base de datos, NO envía correos, NO matricula y NO confirma cupos. La ficha se prepara localmente en el navegador para revisión/impresión. Si la escuela necesita recibir y administrar automáticamente fichas, requerirá un servicio de formularios o backend con políticas de privacidad y acceso seguro (especialmente por tratarse de niños). Evita recopilar RUT, historial médico, domicilio de menores u otros datos innecesarios.

Para publicar gratis con GitHub Pages: sube los archivos y la carpeta assets/ a la raíz del repositorio, entra a Settings > Pages, selecciona branch main y /root.

Personalización: cambia categorías, rangos y horarios en index.html; si cambian los años de las categorías, actualiza también el objeto ranges en script.js. Reemplaza el número de WhatsApp en los enlaces y en script.js.
